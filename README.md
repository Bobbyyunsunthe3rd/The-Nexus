# The Nexus

CRM Analytics Dashboard Generator

## Features

- Excel/CSV Upload
- Lead Analytics
- Sales Performance Dashboard
- Campaign Analysis
- AI Generated Business Insights

## Tech Stack

- HTML
- CSS
- JavaScript
- Flask
- Chart.js
- Gemini API

## Setup

1. Install requirements

pip install -r requirements.txt

2. Create a `.env` file

GEMINI_API_KEY=your_api_key_here

3. Run

python backend/app.py
